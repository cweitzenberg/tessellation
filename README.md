Origami Triangle Grid — Setup & Run

Requirements
Python 3.12+

Two packages: pygame and numpy

Steps
1. Install Python
Download from python.org and install it. Make sure to check "Add Python to PATH" during installation.

2. Download the file
Save origami_grid.py to a folder on your computer.

3. Install dependencies
Open a terminal (Command Prompt or PowerShell on Windows, Terminal on Mac/Linux) and run:
pip install pygame numpy

5. Run the program
Navigate to the folder containing the file and run:
python origami_grid.py


Controls
Mouse hover	- Highlight a grid line
Left click	- Select a line / trim a vertex
Scroll wheel - Zoom in/out
W / A / S / D or arrow keys	- Pan the view
Ctrl+Z - Undo
C - Clear all creases
R	- Reset view and creases
Escape	 - close popup
